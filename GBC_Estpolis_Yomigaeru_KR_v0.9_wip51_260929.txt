WIP50 대비 변경
- 세이브 슬롯 목록(「어디에 저장?」 등)의 이름이 그 슬롯에 저장된 이름으로 나옵니다.
  전에는 모든 슬롯을 지금 플레이 중인 주인공의 음절로 그려서, 이름이 다른 슬롯이 틀리게 보였습니다.
- 「꼭」 글자를 한 번 더 고쳤습니다. WIP49/50은 ㅗ 꼭지를 한 칸 옮긴 정도라 여전히 「끅」처럼
  보였습니다. ㄲ 아래 한 줄을 줄이고 꼭지를 가운데에 두 칸으로 그렸습니다(꼭·꼼·꽃 등 17자).

!! WIP49는 쓰지 마세요 !!
WIP49는 이름 음절표를 옮긴 자리가 잘못돼, 세이브를 불러오자마자 게임이 그 메모리를 지워
이름이 곧바로 「가가」가 됩니다. 실제 에뮬레이터로 확인하다 발견했습니다.
WIP50부터는 실제 플레이 중 쓰기 추적으로 게임이 절대 쓰지 않는 자리를 찾아 옮겼습니다.
WIP49에서 불러와 다시 저장한 슬롯은 이름 음절표가 0으로 저장돼 「가가」로 남습니다.
WIP48 이전 세이브는 WIP51에서 그대로 이어 하시면 됩니다.

로로니니님 제보 13건을 모두 고쳤습니다.

1. 교회에서 마법을 배울 때 「에스트든시천터네」 (세이브 1)
   「は↵」「をおぼえた」 두 조각이 일본어 그대로였습니다. 코드가 글자 수를 정해 두고
   복사하는 조각이라 미번역 검사에 걸리지 않았습니다.
   → 「웨인 / 에스트 배웠다」
   (이름·마법 이름이 실행 중에 들어가서 을/를은 정할 수 없어, 「EXP 획득」처럼 조사를 뺐습니다)
2. 비전서로 팀 기술을 배울 때 「드라이브든시천터미난」 (세이브 1)
   같은 원인(「をおぼえます」) → 「드라이브 배웁니다」
3. 고대의 동굴 마법서 두루마리 「짜르지안든함테네_」 (세이브 3)
   같은 원인(「を覚えた。」) → 「짜르지안 배웠다」
4. 장비·테자·대열 변경 확인창의 「예 / 아니오」 줄이 「아욘드이E」
   bank6 도움말 표가 20칸이 아니라 21칸이었습니다. 21번째 칸이 대열 변경 문장의 꼬리
   「はい いいえ」를 함께 쓰고 있었는데, 추출이 이 칸을 빠뜨렸습니다. 그래서 원래 자리에
   다른 문자열이 덮어써졌습니다. 세 확인창 모두 이 한 줄을 씁니다.
   → 「네 / 아니오」 줄을 따로 번역. 대열 변경 문장 뒤의 「■배」도 사라졌습니다.
5. 스윙(워프) 목적지 지명 깨짐 (세이브 4)
   목적지 목록(bank52)이 번호로 찾아가는 표라 코드 참조가 없습니다. 그래서 검사 도구가
   「디버그 메뉴」로 보고 건너뛰고 있었습니다.
   → 16곳 모두 번역(파토스·알바노·마자리·샨타오·리온·카안·토마스·알슈타트·코비·
     엘코라노·레드우드·레이독·탄바·모로고로·미디·구르다크). 보내 주신 정답 목록과 대조했습니다.
6. 몬스터 2마리 이상과 싸우면 이름이 「가가」로 바뀜 (세이브 1)
   이름의 한글 음절표를 WRAM의 「두 번째 적」 자리에 두고 있었습니다
   (예전에 빈 곳인지 확인할 때 적이 1마리인 전투만 봤습니다).
   → 음절표를 적·고대의 동굴과 겹치지 않는 자리로 옮겼습니다.
7~9. 설명문 끝이 잘림·깨짐: 드래곤 에그 「알이(다)」, 바니의 쟁반, 차이나드레스
   설명창이 설명문을 35바이트(전투 37바이트)까지만 읽습니다. 한글 2바이트 글자 때문에
   이 길이를 넘은 설명이 잘리거나, 끝이 없어 이전 글자 찌꺼기가 이어졌습니다.
   → 44바이트까지 읽게 고쳤습니다.
10. 「버니 / 바니」 → 아이템 이름도 「바니의 검·옷·귀·쟁반·반지」로 통일
11. 차이나드레스 → 「다리가 살짝 보여 요염하다」
12. 아이마 「웨인 님」 → 원문 どの(殿)대로 「웨인 공인가…」「…힘을 빌릴게, 웨인 공.」
    「공은 빼, 그냥 웨인.」 같은 호칭을 쓰는 다른 인물 대사 1줄도 「공」으로 맞췄습니다.
13. 「꼭」이 「끅」처럼 보임 (대사 글꼴)
    ㄲ+ㅗ+받침(꼭·꼼·꽃 등)에서 ㅗ 꼭지가 ㄲ 왼쪽 획 바로 밑에 붙어 있었습니다.
    → ㄲ 아래 한 줄을 줄이고 ㅗ 꼭지를 가운데에 두 칸으로 그렸습니다.

같은 종류라 함께 고친 것
* 설명문 11건이 중간에서 잘려 있었습니다(예: 「지르콘으로 만든 검이다」 → 「지르」).
  복사 루프가 특정 바이트에서 멈추는 문제입니다. 그런 바이트가 한글 코드에 생기지 않게 했습니다.
* 적 4마리 전투: 치트 설정과 띄어쓰기 처리용 메모리가 「네 번째 적」 자리와 겹쳐 있었습니다.
  적 데이터가 망가질 수 있었습니다 → 함께 옮겼습니다.
* 목록 띄어쓰기 처리용 메모리가 고대의 동굴 데이터와 겹쳐 있었습니다 → 옮겼습니다.
* 치트 메뉴(SELECT+START)는 닫을 때 고대의 동굴 데이터 자리를 지웁니다. 그래서 고대의 동굴
  안에서는 치트 메뉴가 열리지 않게 했습니다. 동굴 밖에서 설정한 값은 그대로 적용되고,
  SELECT+B 즉시 회복은 동굴에서도 됩니다.
* 미번역 검사에 「코드가 직접 가리키는 문자열」 검사를 추가했습니다(이번 1~3번 종류).

남은 것 / 주의
* 이미 「가가」가 된 뒤 저장한 슬롯은 음절표 자체가 0으로 저장돼 있습니다. 그래서 원래 이름으로
  돌아오지 않습니다. 보내 주신 세이브는 1번 슬롯이 「웨인」으로 멀쩡합니다.
  세이브 3의 4번 슬롯은 적 데이터가 섞여 저장돼 있어 이 판에서 「가가」로 정리해 불러옵니다.
* 이번 판은 보내 주신 세이브로 에뮬레이터에서 직접 확인했습니다.
  - 교회 습득 「웨인 / 리·아 배웠다」, 비전서 「드라이브 배웁니다」
  - 고대의 동굴 두루마리 「미라르 배웠다」「데르데 배웠다」
  - 장비·대열 변경 확인창 「네 / 아니오」
  - 드래곤 에그·바니의 쟁반·차이나드레스 설명 끝까지 표시
  - 소 2마리 전투에서 이름 「웨인」 유지(wip48은 같은 전투에서 「가가」 재현)
  - 저장 화면 슬롯 이름이 각 슬롯 이름으로 표시, 닫은 뒤 현재 이름 유지
  스윙 목록·테자 확인창은 신전 안이라 써 볼 수 없었습니다. 실제 코드 모의 실행으로 확인했고,
  테자는 장비·대열과 같은 「네 / 아니오」 줄을 씁니다. 아이마 대사는 이벤트라 문장만 확인했습니다.

이 판의 내용
- 메뉴·대사 전체 한글화 (대사 4,526건), 시리즈 공통 명칭 (사광신·가데스·아몬·에리누·디오스·허공도)
- 대사·전투 메시지 글꼴: Mona 8x12 (SIL OFL 1.1, Monad ABXY)
- 반각 띄어쓰기: 대사, 8x8 메시지 창, 설명창·목록 (공백 2칸 이상 연속과 이름 입력기는 원래 폭)
- 치트 메뉴와 단축키, 치트 설정은 게임 세이브에 함께 저장

조작
- SELECT 누른 채 START: 치트 메뉴 (필드에서, 고대의 동굴 제외)
  일격필살 / 방어력 30배 / 경험치 배율 x1~30 / 골드 배율 x1~30 /
  전투 후 회복 / 던전 즉시 탈출 / 인카운터율 (없음·절반·보통·2배·4배)
  ↑↓ 항목, ←→ 값 변경, A 결정, B·START 닫기
- SELECT 누른 채 B: 즉시 회복 (HP·MP·상태 이상, 전투 밖에서는 부활 포함)
- SELECT 단독: 원래대로 대륙 지도 (버튼을 뗄 때 동작)
- 인카운터율 「없음」이어도 이벤트·보스 전투는 그대로 일어난다.

주의
- 패치는 아래 일본판 원본 ROM에 한 번만 적용한다. 이미 한글화한 ROM에 다시 적용하지 않는다.
- 다른 빌드의 즉시저장(스테이트)은 피하고 인게임 세이브로 이어서 한다.
